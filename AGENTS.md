# Работа над проектом

Это учебный проект по архитектуре микросервисов AI Chat Platform. Описание системы и текущих компонентов — в [README.md](README.md).

Основной исходник схемы — `Microservices.drawio`. Решения и причины изменений записываем в `DECISIONS.md`. Промежуточные правки не коммитим как релиз.

## Завершение версии схемы

1. Сохранить схему, обновить README и записать изменения с причинами в `DECISIONS.md` под новой версией.
2. Выполнить `make png`, проверить полученный `Microservices.png` визуально и запустить `git diff --check`.
3. Закоммитить исходник схемы и документацию, поставить тег версии `vX.Y`, отправить коммит и тег в GitHub.
4. Создать GitHub Release для тега. Основной файл релиза — `Microservices.drawio`, который можно открыть в draw.io; для быстрого просмотра приложить `Microservices.png`. Краткое описание изменений взять из раздела версии в `DECISIONS.md`.

Отдельный changelog не ведём: его источник — `DECISIONS.md`. PNG в Git не добавляем.

## Рендеринг в sandbox

Локальный draw.io при `make png` может завершиться с `Abort trap: 6` внутри sandbox. В этом случае повторить `make png` вне sandbox с повышенными правами: так экспорт работает. После этого визуально проверить PNG.
